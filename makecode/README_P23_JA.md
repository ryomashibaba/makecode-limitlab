# MakeCode LimitLab P2.3 — FAST METRO DISTRICT（都市施工の基礎）

**P2.3はMinecraft Education実機未検証です。GitHub CIの模擬PASSは実機PASSではありません。**

## 目的と確定済みの出発点

P2.0では単一`clone` 262,144ブロックを全域一致で実機PASS。P2.1では大規模な細分化施工が遅すぎたため、SOURCE全域PASS／CLONE 9/36時点でユーザーSTOP。P2.2.1では309,386ブロック相当のFASTモデルを69回のfill＋2回のclone、550回の代表点チェックで実機完走し、**体感1〜2分**だったとユーザーから報告されました。実時間の自動計測や全域完全一致は実施していません。

P2.3ではブロック数の限界更新を一時停止し、**巨大都市生成につながる道路・街区・複数の建物・中央公共空間を、事前計算した少数のMinecraft命令で施工できるか**を調べます。

## 作るもの

- **192×192ブロックの3×3都市街区**。高さは施工基準面から最大84ブロックの範囲内。
- **幅12ブロックの道路網**と交差点、金色のセンターライン、舗装された敷地境界。
- **8棟の立体建築**。高低差のある3種類のオリジナルタワーを構築し、それを**5回の大きめの`clone`**で複数の街区に展開します。
- 角柱、建物の階床、開放的な窓の区画、外壁の横方向ライン、屋上のセットバック、都市の門柱を表現。
- **中央街区を開放型の公共広場**とし、中央の塔と4基のモニュメントを建築。中央に巨大タワーは置きません。
- コピー後に各建物の屋上に異なる冠部を追加する**部分変更処理**を含みます。

P2.3のブロックパレットは、すでに動作実績のある`STONE`／`GOLD_BLOCK`／`AIR`だけです。**近未来の高品質な都市景観が最終完成する段階ではありません。** ガラス、照明、形状ライブラリ、schematic変換、多街区の自動都市拡張はP2.4以降の別の品質・互換性検証を必要とします。P2.3は機能検証のための都市プロトタイプです。

## 施工の構成

| 順序 | 工程 | 内容 |
| --- | --- | --- |
| 1 | `PLAN` | 都市の各矩形、寸法、建物・道路の位置を**全てMinecraftへの書込前に確定** |
| 2 | `PREFLIGHT` | 都市予定領域の**75点だけ**がAIRか確認（全域保護ではない） |
| 3 | `ROADS` | 道路・舗装・街区境界 |
| 4 | `PROTOTYPES` | 3種類の独立タワーの躯体・階床・屋根 |
| 5 | `CLONE` | 同じ原型を別街区へ**5命令**で複製。複製対象は各36×高さ×36、最大262,144以下 |
| 6 | `PLAZA` | 中央公共広場とアート・モニュメント |
| 7 | `DETAIL` | 複製タワーの冠部を変化させ、地区の門柱を追加 |
| 8 | `SAMPLE` | 道路、8棟の基礎・角柱、中央広場など**18点**を調べる |

`fill`命令は事前計算で32,768ブロック以下へ自動分割し、`clone`は事前計算で262,144ブロック以下と検査します。前工程で成功した単一命令のブロック数を上回る実験はしません。道路や建物の層は、意図的に上書きする順番で施工します。

### FASTの品質表示

`FAST_COMPLETED_SAMPLED`は、すべての計画命令の呼出しを完走し、ネイティブ`clone`の返り値と代表点のブロック状態が確認できたという意味です。**街区内すべてのブロックを検査しておらず、既存建築の保護や仕上がりの美しさは保証しません。** P2.1のような全域照合は、この高速実機試験の必要条件にはしていません。

## 操作方法

1. [GitHub main最新版ZIP](https://github.com/ryomashibaba/makecode-limitlab/archive/refs/heads/main.zip)を解凍し、`makecode/COPY_P23.cmd`を実行して**COPY OK**を確認。
2. **新規の破棄可能なLimitLab専用Minecraft Educationワールド**を強く推奨。試験済みワールドで行う場合は、既存施工物や地形、他の建築と**施工予定の192×192×84すべてが重ならない未使用空間**であることを確認。
3. MakeCodeのJavaScriptを`Ctrl+A`→`Ctrl+V`で貼り替え、**File Read & Write拡張機能を維持**し、エラー0件を確認して再生。
4. まず`labarea23`で現在位置を基準にした座標を表示。何も建築しないコマンドです。
5. 問題がなければ、`labcity23`を**1回だけ**入力します。すぐに`COMMAND RECEIVED`の表示、その後`PLAN`→`PREFLIGHT`→`ROADS`→`PROTOTYPES`→`CLONE`→`PLAZA`→`DETAIL`→`SAMPLE`の順に進みます。
6. `TEST FINISHED`または`TEST STOPPED`と表示されたら、`Downloads\MakeCode_LimitLab\results\USER_UPLOAD_THIS_P23_STATUS.csv`をこの会話へ送ってください。途中に止まった場合も同じCSVで診断可能です。

補助コマンド：`labstatus23`（進捗の表示）、`labstop23`（協調停止）、`labreport23`（結果再表示・再施工なし）。大きなMinecraft API命令がハングした場合、即時停止や最終通知を保証できません。

**P23_ONCE.txtは新しい一回限りの実行ラッチです。** 以前のP22/P221ラッチ・結果は保持され、`COPY_P23.cmd`を再実行してもP23の使用済みラッチはリセットされません。ワールドの清掃、ラッチの削除、失敗命令の自動再試行は行いません。

## 性能・品質の評価方法

前工程で本人が報告した実行時間は「約1〜2分」です。今回は`fill`命令数、`clone`5回、検査数をCSVに残しますが、**実際の経過時間を測る機能はまだありません**。都市のオブジェクト数・規模・品質が以前と異なるため、単に所要時間を比較しただけで何倍高速化したとは言えません。

同じワールドで無断再試行を繰り返さず、まず1回の実機試験で命令の実行結果と、道路・建築・広場の見た目を確認してください。最終的な都市の美観は目視評価と今後のデザイン改修で高めていきます。
