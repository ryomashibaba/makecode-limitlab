# MakeCode LimitLab P1.3 — 耐久試験切り分け版

## 実機での問題

P1.0は4,096/16,384ブロック、更新、256KiB I/OをすべてPASSしました。`ENDURANCE_QUICK`は進捗が見えず、利用者の`labstop1`で最終的に`STOPPED USER_STOP`となりました。P1.0のfillの最大単発施工は512ブロック（16×1×32）であり、一般的な `/fill` の32768制限を超えていません。**停止の原因は未確定**です。

## 今回の方針

既存の大規模建築を再実行しません。新しい空き領域の64ブロックだけを検査・施工し、24回の短い耐久テスト中に4回ごとにCSVを書きます。小さなブロック更新、計算、ファイル書込・読戻しを組み合わせて検証します。

## 手順

1. GitHubから本パッケージを取得し、`makecode/COPY_P13.cmd` をダブルクリックして `COPY OK` を確認。
2. 同じ専用テストワールドのMakeCode JavaScript欄で Ctrl+A / Ctrl+V で**全部入れ替える**。File Read & Write拡張機能は残す。
3. 赤い問題が0件なら再生し、チャットで `labrun13` を1回だけ入力。完了メッセージまたは停止メッセージまで待つ。
4. `Downloads/MakeCode_LimitLab/results/USER_UPLOAD_THIS_P13_STATUS.csv` を送る。

状況確認は `labstatus13`、途中停止は `labstop13`。**`labrun13` の再実行は禁止**（プログラム自身も同一セッションで拒否）。`SOAK30`は、`QUICK PASS`を確認した後に必要なら `labsoak13` で30秒相当の追加検証ができますが、初回は不要です。

## 安全・制約

- テストワールド限定。世界の座標は実行時プレイヤー位置 + X12/Y16/Z28 を基準に8×1×8。全64ブロックが空気の場合にだけ変更。
- 既存P1.0の構造物と結果には触れない。空間占有・検証失敗・途中停止では自動削除しない。途中からブロックが残ることがある。
- P1.3の停止はコード側の協調処理。Minecraft全体が応答しない場合の強制停止は保証できない。
- 24回×100msの待機要求は最低2.4秒に相当しますが、**実際の所要時間は未知**。進捗CSVを参照。
- MakeCodeの実機コンパイル・稼働は未検証。Windows上のコピー用スクリプトはオフラインチェックのみ。
- P1.0の既存実測CSVは公開リポジトリに追加しない。

クラウドリポジトリ内Chatを基本とし、Workは明確に効率が上回る／必須の場合のみ。ローカルWorkは原則使用しない。ユーザー作業はコード貼付・実機確認程度。
