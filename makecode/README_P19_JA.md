# MakeCode LimitLab P1.9 — 単一clone 131,072ブロックへの拡張

## 研究の出発点（Minecraft Education実機）

- **P1.6**：単一fill / clone 32,768ブロック各PASS。65,536ブロックの分割施工もPASS。
- **P1.7**：単一fill 32,800ブロックはNO_WRITE。単一clone 32,800ブロックはPASS。
- **P1.8**：単一fill 32,775ブロックはNO_WRITE。単一clone **33,024・40,960・65,536ブロック**がすべて実機PASS。
- **P1.9はまだMinecraft Education実機未検証**です。自動CIの成功は実機PASSを意味しません。

この結果から、fillの32,768付近の境界調査とcloneの大規模化は別テーマに分けるのが合理的です。P1.9では**cloneのサイズだけ**を進めます。過去の32,768/32,800/65,536ブロック単一命令試験を繰り返しません。

## P1.9の1回実行試験

| 順序 | 操作 | 単一cloneの対象 | 前提条件 |
| --- | --- | ---: | --- |
| 1 | コピー元を1024ブロック以下のfillで組み立てる | **131,072**ブロック（32×64×64） | 全候補をAIRで事前検査 |
| 2 | 単一clone | **98,304**ブロック（32×48×64） | コピー元131072を全タイル検証 |
| 3 | P1.9自身のclone先だけAIRに戻す | 98,304ブロックを安全な小分けで初期化 | 98,304単一cloneが完全一致でPASS |
| 4 | 単一clone | **131,072**ブロック（32×64×64） | コピー元・複製先・AIR参照を再検証 |

98,304で失敗したら、それより大きな131,072は**自動実行しません**。2回とも成功したとしても、Minecraft APIの普遍的な最大値と断定しません。

## 安全性

- **使い捨てのLimitLab専用テストワールドのみ**で使用してください。他のMinecraftAIBuilderや重要な建築ワールドには実行しないでください。
- 書込領域はsource 131,072ブロック、clone先131,072ブロック、参照AIRと参照GOLDが各512ブロック。参照GOLD以外はAIR比較で事前チェックし、不一致・読み込めない可能性がある領域を採用しません。
- X/Z方向へ分散した**最大6候補**を読み取りのみで調査。候補ごとの不合格領域をCSVに保存。6件すべて不合格なら施工せず終了。
- GOLDコピー元は128回の小さなfill（各1024）で構築し、参照512ブロックとの完全比較を256タイルで行います。
- 単一cloneの返り値と全域512ブロック単位比較を両方確認。98,304の試験では、**指定していない上部32,768ブロックがAIRのままかも検証**。
- クローン先を初期化するのは第2段階へ進む準備として、98,304の試験がPASSした場合だけ。ほかの施工物は触れず、失敗時に自動削除・自動再試行しません。
- 進捗はCSVのBEGIN/PROGRESS/PASS/LIMIT/ANOMALY/STOPへ保存。
- Minecraft側で命令がハングした場合、内部から強制キャンセルできず、TEST FINISHED/STOPPEDの表示を保証できません。極端に遅い場合は`labstatus19`を使い、`labstop19`で協調停止要求ができます。ただし命令の実行中には即時停止できません。
- 計時ベンチマークではなく容量・正確性の調査であるため、実行所要時間は未保証です。

## 操作（Minecraftではコマンド1回）

1. [GitHub最新版ZIP](https://github.com/ryomashibaba/makecode-limitlab/archive/refs/heads/main.zip)をダウンロードして解凍します。
2. `makecode/COPY_P19.cmd`を実行して`COPY OK`を確認（エラー時は同フォルダの`PASTE_THIS_P19.ts`を使用）。
3. MakeCode JavaScript欄を`Ctrl+A` → `Ctrl+V`で貼り替え、**File Read & Write**拡張機能を保持し、エラー0件で再生します。
4. **破棄可能なLimitLab専用テストワールド**にて`labauto19`を**1度だけ**実行します。
5. Minecraftチャットに`========== TEST FINISHED ==========`または`========== TEST STOPPED ==========`と表示されたら、`Downloads\MakeCode_LimitLab\results\USER_UPLOAD_THIS_P19_STATUS.csv`をこの会話にアップロードしてください。

チャットコマンド：`labstatus19`は現在の工程、`labreport19`は結果を再表示（**再施工なし**）、`labstop19`は協調停止、`labplan19`は読み取り専用の工程案内です。
