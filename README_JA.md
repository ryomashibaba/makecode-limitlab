## 手元の操作（今回のP1.1基盤）

**Minecraftでコードを貼り直す必要はありません。** P1.0が実機未実行の場合は、以前配布済みの手順で実行してください。

Webダッシュボードは `docs/index.html` をダブルクリックするだけでローカル表示できます。「CSVを読み込んで判定」から `USER_UPLOAD_THIS_P10_STATUS.csv` を選んでください。アップロードはされず、ブラウザー内で検証します。結果ファイルは改名・移動されません。

コマンドラインでCSVを調べたい場合（開発用）:

```bash
python tools/limitlab_results.py /path/to/USER_UPLOAD_THIS_P10_STATUS.csv
```

## GitHubに移す場合（Publicで確定）

1. GitHubに専用リポジトリを作成し、このフォルダの中身を配置。
2. リポジトリの Actions を有効にすると、コミットごとにPython・JavaScriptの検証が自動で走る。
3. GitHub Pagesを使う場合は Settings → Pages → Deploy from a branch → main /docs と設定。
4. サイトは静的ファイルだけで動き、CSVは**利用者がブラウザーで読み込む**。共有リポジトリへユーザーのCSVを自動公開しない。

GitHub Pagesの利用条件はリポジトリの公開設定やプランによって異なります。公開したくない場合は、サイトをローカルで使うか、公開許可について別途決めてください。

**このアーカイブの作成時点ではGitHubリポジトリ作成・外部公開は未実施です。公開手順は PUBLISH_JA.md を参照。**

## 安全と性能の注意

- ダッシュボードは閲覧・ファイル読取のみで、Minecraftのブロックを一切書き換えません。
- P1.0本体は専用テストワールド限定。無条件に繰り返し実行しないでください。
- P0.6・P0.7の時間はファイル時刻差に由来する概算であり、速度倍率の確定根拠にはできません。
- P1.0の標準実験は`labauto1`。`labsoak1`は5分の任意耐久試験であり、まだ必須ではありません。
- `docs/` のCSV読込は5MBのサイズ制限を設けています。測定結果をサーバーへ自動送信しません。

## プロジェクトの不変方針

1. クラウドプロジェクト内のChatを基本とする。Cloud WorkはChatより明確に効率が高い、またはWorkでなければできないときだけ。
2. ローカルWorkは原則使わず、ユーザーはMakeCodeへの少量の貼付と、時折の実機検証程度。
3. 既存MinecraftAIBuilderを変更せず、専用実験ワールドを使用。
4. 多工程をまとめて実装するが、実機未検証の領域では段階的な安全停止と検証を維持する。
5. クラウドGitHubリポジトリをPublicで新設する許可は得ています。Minecraft世界の操作は別途実機で段階確認します。
