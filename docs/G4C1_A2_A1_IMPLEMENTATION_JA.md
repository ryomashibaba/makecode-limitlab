## 2. 実装方針：巨大都市感を出し、スピードを維持

元の372×372配置、各3×3区画、道路幅12、Y+1の歩道・横断帯、32棟と4広場、原型Fill 386・Clone 49を維持。全4地区の高速複製完走後、**追加51回の限定Fillで大規模な建築質量を変える**。新しい追加形状は全てY+2以上に置き、元の歩行可能路面Y+1には一切書き込まない。

| 地区 | 主役として追加する造形 | 大きなシルエット差 |
|---|---|---|
| A 都心商業（北西） | 商業塔の巨大な上部長方形クラウン、別棟の立ち上がる二連構造、広場の高い門型フレーム | 「縦に伸びる塔冠と公共軸」 |
| B 文化・公共（北東） | 中央広場に大きな四辺梁と四本支持柱からなる開放型大屋根、隣接棟の水平キャノピー | 「水平方向に広い公共大屋根」 |
| C 居住・緑化（南西） | 複数ビルの広い緑の屋上テラスと、広場上部の階段状グリーン・キャノピー | 「大量の緑化した段状スカイライン」 |
| D 研究・技術（南東） | 建物に両端で接合する高架ガラス連絡橋2本、最高層の双縦翼、研究広場の門フレーム | 「連結構造と技術的双翼」 |

装飾だけの変更ではなく、数十ブロックの幅・高さを持つフレーム・屋根・連結橋を導入する。新しい塔・橋の支持構造は道路や地上入口に触れない位置へ配置。文化広場の支持柱も広場の四隅に置き、中央への通路を塞がない位置を選択する。実際の歩行可能性やMinecraftのレンダリング上の完成度は**実機後に判定**。
