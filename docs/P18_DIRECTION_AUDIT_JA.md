## P1.8で確定した設計改善

1. P1.6 / P1.7ですでに確認できた32,768・32,800ブロック実験を無駄に再実行しない。
2. fillは32,775という境界近傍の別形状を1回だけ試す。cloneは33,024 → 40,960 → 65,536の段階式で、失敗した場合はそこで終了。
3. fillでLIMITを観測してもcloneへ独立に進む。cloneの次段階前は所有する試験領域のみ初期化する。
4. 参照領域を分離し、全候補をAIRで全タイル確認。占有や検証不能ではfail-closed。不成功・部分施工・返り値不一致をCSVで分ける。
5. 制御が戻る場合、成功・境界観測・安全中断いずれもMinecraftチャットに明確なTEST FINISHED / TEST STOPPEDを表示。labreport18で再表示可能。
6. Chatでの実装を基本とし、不要なWork利用やPC側の反復操作をしない。

## 次工程へ進むゲート

P1.8の実機CSVが得られるまでは、本版のMinecraft施工成功を宣言しない。実機完了後、fillの不成功が体積・形状・チャンク条件のどれと整合するかを検討し、cloneの成功境界を基に次版を設計する。長時間耐久の再調査はこの本筋から分離する。
