# G4-C7 A10 — Inhabited Double Canyon / 立体文化地区・厚肉中空双殻

**基点：A9 Draft PR #45 のHEAD 8dd0f91c3225fc01e79d3178b69f172a18b3126b。**
**判定：ART HOLD／Minecraft施工禁止／旧都市への統合禁止。**

## なぜこの工程を始めたか

A9は経路の3D表面干渉を67→45に減らし、足元支持不足を1→0に改善した。しかし、4視点の実GLB比較を目視すると、美術面では主アーチ以外の内部が広い空地に見え、大規模な超未来文化地区に見合う建築的密度・用途空間を欠く。衝突箇所だけを延々と切っても根本の美術問題は解けない。

A10の目的は、既存主アーチ・斜裂ヴォールト・上空スロットを残し、**左右非対称の厚肉の居住可能な概念空間と、それらの間の立体峡谷**を新しい主役にすること。小規模ビル群の追加、色替え、装飾フィン、薄い屋根は不可。

## 実3D形状として作るもの

- WEST：長さ約78概念単位の、低く長くうねる中空の厚い建築帯。外殻は閉じた実体積で、内部の連続した空間をボリューム差分で抜く。実側面開口を2箇所、開放された2端部を作る。内部に幾何学的な床も生成する。
- EAST：長さ約70概念単位で、WESTより高く立ち上がる非対称の厚い文化的建築帯。WESTと形状・高度が同じ反復箱にならないよう別の非線形中心線を採用する。実際の中空を切り、2箇所の側面開口と利用床を作る。
- 各帯の下に地上接続する太い支持ピア3本、計6本。浮いて見える意味不明の薄い床にしない。ただし静荷重・耐震・消防安全は未検証。
- 両岸の間に**太い彎曲した横断空間2本**。ただし接続部で自由歩行できるかは本工程で未認定のため、その旨をJSONに残す。
- 差分の正面・斜視・側面・俯瞰画像を、A9/A10で固定カメラ・同縮尺で生成する。

これは従来の22棟都市を自動的に17棟＋複合体へ統合するものではなく、B文化地区単独の美術探索。都市施工・マイクラボクセル変換・既存ワールドへの利用は禁止。

## 進め方・厳格QA

実GLBモデルの体積削除による**真の中空部**を検証する。開口は材質・名前の変更や単にAIRを書くだけではなく、ブーリアン後に閉メッシュであることと切除体積を確認する。建築内部の概念床面積は中心線長×概念幅の近似値であり、実際の許可人数やMinecraft可歩行性には換算しない。

A9と同じ331地点、993点の足元支持、3D包絡（半幅0.65、足元0.15〜3.25）、負の対照、13軸SATを用いて、地上→回廊→主アーチ通路の回帰を検査する。**旧45地点の干渉・未支持0を悪化させないこと**。新しく造形した建築内部や2本の横断建築の経路はこの旧QAでは検証されないため、A10の成功で内部が使用可能・上下移動可能とは報告しない。

期待成果：新規GLB/OBJ、実3D面積・中空比・開口情報JSON、A9/A10の固定4視点PNG、再生成用ソース、専用CI。すべてGitHubの専用Draft PRを正本として保存。BlenderのBLENDやEEVEE生成ができなければその事実を明示する。

## 横断方針監査

- ART-FIRST：施工制約や現代建築の用途分類を、造形の初期段階に持ち込まない。内部が中実に見える・低層箱に見える場合はREJECT。
- 旧G4-C6実機FAST_COMPLETED_SAMPLED_NOT_EXACTの施工成功・施工速度不明を維持。A10は実機施工しないため時間短縮を推定しない。
- GitHubのみを最新正本とし、A5〜A9のGLB/BLEND、CSV、ZIP、USED、旧ワールドを変更しない。
- 1工程ごとに「実装→幾何QA→4方向画像→美術審査→Draft PR→GitHub保存」をまとめ、資料だけの極小工程を増やさない。
- ワークフローの無関係な全起動は効率問題。A10専用CIはコード・文書・ワークフローのpath-filterを付与し、成果物だけのコミットでは再実行させない。既存の安全CIゲートを無断停止しない。

**最終美術評価は4視点画像を確認した上で判断する。完成を先取りしない。**


## A10の再読込QAで判明したA9基準値の差異

**同一検査でもA9の検証時メモリ上のモデルと、GitHubへ保存されたGLBの再読込では端部の支持結果が違った。** A9当時の報告は支持不足0/993だったが、A10がコミット済みA9 GLBを再読込してA9経路を独立再検査した結果、**端部で1/993が支持不足**となった。許容値を勝手に緩めない。A10では地上アプローチの端部をZ=70から72.2へ実床延長し、再読込後の支持不足を0へ修復した。

この発見は旧A9実測の捏造を意味せず、**検査対象をin-memory/round-tripで区別すべきQA上の教訓**である。A9とA10を比較するとき、必ず「保存されたGLB再読込後」という同一条件で比較する。中空空間の内部歩行・2本の横断床と左右両岸の到達経路・新規構造と既存殻の実固体干渉は引き続き未認定。

さらに初回の4視点画像を実際に審査した結果、概念床面積が増えても、建物が小さな2基のポッドに見え、主アーチ内を支配する未来都市的な質量と高さが不足していた。このため、**A10同一ブランチで両岸の殻を高く厚く、2本の横断構造を大きくする造形修正を実施**。美術評価は継続ART HOLD。単なるCIの合格は美術合格ではない。
