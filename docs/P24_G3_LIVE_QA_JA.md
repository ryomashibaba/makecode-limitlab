# MakeCode LimitLab — P2.4 / G3 Minecraft Education実機QA

## 最重要：試験ワールドの承認方針（2026-10-19更新）

**LimitLab専用の破棄可能な試験ワールドについて、新規施工・再試験を原則として事前承認済みとして扱う。**
毎回の形式的な許可確認は不要。ただし、**既存の重要ワールド・第三者のワールド**、試験範囲外への書き込み、旧ラッチ・CSVの上書きや削除、古い証拠の廃棄、未検証の危険な操作などは慎重に扱い、必要に応じて個別確認する。

承認済みであることは、Minecraftを操作できる手段があるという意味ではない。
Chat主体・OMEN 1台・Work原則不使用は維持する。Minecraft操作は現在OMENでの人手操作が必要。

## この工程の位置づけ

P2.3（192×192、幅12道路、8棟、中央公共広場）は**未だ実機未検証**。
G3はG2の一括準備とG1のCSV解析に、**ローカル実機証拠のZIP化**を加える。
実機が終わらなければG3の「ソフトウェアCI PASS」と「Minecraft実機PASS」を混同しない。

## Windows / OMENでの最短操作

この開発ブランチ `dev/p24-g3-hardware-evidence` をGitHubから既存リポジトリに取り込む。
既存作業を破壊しないよう最初に `git status` を確認してからブランチを切り替える。

1. プロジェクトの最上位にある **`RUN_P24_G3.cmd`** をダブルクリックする。
2. `PREPARED` と表示された場合、**新しい破棄可能な専用ワールド**をMinecraft Educationで開く。Code BuilderのJavaScriptへ貼り付け、File Read & Write拡張を保ち、エラー0件を確認。
3. 読み取り専用の `labarea23` で施工予定位置を確認。地形・既存建築と干渉しない未使用の試験領域だけを対象とする。
4. `labcity23` を**1回だけ**入力する。これは本ユーザー方針によりテスト用ワールドで事前承認されている。重複施工・自動リトライはしない。
5. 試験終了後、Windows上で作られた `USER_UPLOAD_THIS_P23_G3_....zip` をこのChatにアップロードする。場所は `Downloads\MakeCode_LimitLab\private_results\g3\`。
6. 都市全体と、道路・タワー・中央広場の見えるスクリーンショットを可能な範囲で追加する。見た目と建築品質の判断には画像や実機目視が必要。

**Minecraftの起動・MakeCode貼付・チャット入力は自動化されていません。**
CMDを押すだけで世界に施工されるわけではありません。

## G3 ZIPの内容

- P2.3の**元のCSVをバイト列のまま**保存
- `G3_EVIDENCE_MANIFEST.json`：CSVのSHA256、ソースのGit blob SHA、処理工程、サンプル完走/停止/未完了の区別
- `READ_ME_JA.txt`：注意事項

個人PCのファイル一覧・ユーザー名・ローカル絶対パス・スクリーンショットを自動で付けない。
**Public GitHubにこのZIPやCSVを置かない。**

### 証拠の信頼範囲

`FAST_COMPLETED_SAMPLED_NOT_EXACT` なら代表点での完走証拠であり、全ブロック完全一致を証明しない。
`STOPPED` は停止した試験、`INCOMPLETE` は未完了。
このZIP自体はMinecraft GUIが動いたことの絶対的な証拠ではない。モデルや推測で実機試験成功を補完しない。

## 失敗時の扱い

`USED_P23`、既存P2.3 CSV、未知のラッチ状態、ソース不一致では準備を中断する。
**ラッチや既存結果を初期化して同じ出力先で再実行することはない。**
新規のテストワールドについての包括的許可は、既存証拠の削除許可を含まない。
再試験の際は、別の出力領域と新しい独立テスト識別子を使う設計が必要（本工程では自動発行しない）。
