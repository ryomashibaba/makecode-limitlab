## 1. D7と異なる設計実験

D7は局所に梁・薄床を置いた。「都市の遠景の姿＋代表人間体験経路を同一原本にする」というD7からの要求に対し、D8では地域に4本の不均質な生活軸、用途を分けた区画、地形、公開学習と制作場、延長1,415.31mの一本の代表公共経路を**同じ完全な研究用GLB/OBJ/PLY**へ入れた。研究対象の最大範囲X -1400..1430m、Y -960..1190m、Z -20..295.657m。

建物は各々6辺のねじれた外皮、2層の実体積、公開テラス、植栽を部分的に持つ。ただし室内は空でない完成住戸ではなく**外形の粗実3D**のみ。建物の高さを高くしただけで美術に優れると見なさない。

D8の比較対照は居住／研究密度だけを大幅に減らし、主要公共経路・現場活動・視点を維持したもの。部分造形の差分効果を見るための対照で、推奨案ではない。

## 2. 全視点比較による厳格な美術判定

- **マクロ遠景**：縦長で同型に見える棟が4本の軸上に分散する。独自の都市として固有性が読めない。「板・棚・巨大壁」から逃れたが**量産された塔群へ退行**。
- **地区視点**：生活の厚みというより別棟の列。地形と建築の結合は弱い。住居・研究の外形差が色や高さ以上に読めない。
- **市民交差点**：長い地上通路に両側の棟が立ち、分野間の活動の相互露出が乏しい。塔の隙間は依然として都市の中心的経験になっていない。
- **公開制作の眼高**：実際の制作活動は小さく、直立の外装と渡り床に注意が向く。幾何レイ上でも遮断を検出。
- **研究眼高**：カメラは施設外形に向き、研究交流対象が本物の活動の断面として見えない。実メッシュで遮断を検出。
- **高所生活眼高**：住居内部・共用室・高所テラスへの実経路も存在せず、ただ建築外面が見える。

**美術判定：G0 ART REJECT**。前案より三角形数・建築密度・地域規模が増えた事実は、美術品質向上の証拠ではない。

## 4. 根本原因と決定

D7での「局所の斜交梁群」に対してD8は「全域の用途区画群」を機械的に追加した。**都市がどう使われるかを外形に反映するという作者方針を、決まったテンプレート区画をプログラム名で分類する方式へ戻した**。これが最大の失敗。

**D8の塔列生成文法は不採用**。同じ建築単体を幾何的に細分化・装飾して延命せず、候補の「都市の固有な空間体験」と「遠景・公共近景が一致する唯一の作者断面」を同時に作る。また、3Dモデルを生成する前に、生活の共通場を一つ決め、何が無ければそこが成立しないかを作者が設計する。

## 6. 再現方法

Python `numpy`・`trimesh`・`vtk`・`Pillow`。

```
python build.py --variant both
python render.py
python audit.py
python scene_visibility_audit.py
```

各案の`study.obj`, `study.glb`, 分類ごとのPLYをレンダラで再読込。`manifest.json`は保存後のOBJ/GLB/分類PLYのSHA256を保有。`audit.py`は生成器をimportせず保存ファイルを独立で読む。`scene_visibility_audit.py`は実PLYの視線遮断。**GitHubに原本が入っているとは、実際のアップロードが確認できるまで主張しない。**
