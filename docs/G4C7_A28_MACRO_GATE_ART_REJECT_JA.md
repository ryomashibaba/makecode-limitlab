**改善できた点：** 細部完成まで進まず、少数の大形態で不合格を確定。A27の1,780三角形／134閉部材に対しA28-A/Bは316／276三角形、18／13閉部材で、同等の初期美術ゲートの判定を先行できた。これは制作・監査の単純化であり、開発速度の実測優位を示すデータではない。

**次の不足・方針修正：** 大形態だけのモデルでは、公共空洞を「機能する都市」として見せる視覚情報がそもそも不足し、巨大殻や屋根として見えやすい。A29は単に低ポリの構造体だけを比較せず、`大空洞→公共交通・広場→見える居住都市断面→巨大主構造`を**同時に仮組みした小規模3D**で審査する。広場・構造・居住の面積や見え方を別々に評価し、内部の使われ方が見えなければ即棄却する。

1. 大きなフォルムが都市を隠さないか、正面・斜視・側面の**実像と内部からの対照視点**で先に検証。必要な断面カット・開口は空間設計として成立させ、撮影だけで内部が見えたと錯覚しない。
2. 都市としての複数尺度を初期から提示する。ただし住宅箱の反復や小窓の数だけでスケールを水増ししない。
3. 「A/Bを棄却したので絶対にアーチ・巨大床・リング・橋を禁止」という恣意的ルールは作らない。**評価するのは構成の有効性・一体感・都市の利用場面と美しさ**。
4. 見かけのサイズの詐称回避。都市の仮定寸法・参照スケールの定義を必ず併記し、同条件の前案OBJ比較を継続。初期アートを正式なMinecraft建築の実現性で縛らない。
