# G4-C7 A2 — 建築の構造型を22棟で作り分ける

**2026-10-24 JST / 施工禁止・設計3D審査工程。** 基準はG4C7 A1の実レンダリング画像の美術REJECT。4地区の平面寸法は異なったが、Bは屋根付き箱、CはU住宅、DはH字研究棟という「同じ部材構成」を繰り返していた。A2ではサイズ・塗装ではなく**空間構成・部材の組み合わせ**を変える。

## 実装した22の独立建築プログラム

| 区域 | サイトごとの役割（都市の主役） |
|---|---|
| A 都心6 | 双塔の業務複合／セットバックの単塔／アトリウム付き非対称二棟／段丘型の業務施設／低層交通ハブ／低層市場 |
| B 文化5 | 厚い屋根と一体の劇場／左右独立展示翼を持つ美術館／高窓のある彫刻展示館／閲覧室と書庫の図書館／屋外観客席のイベント広場 |
| C 住宅6 | 南に開いたU字中庭／L字住棟とテラス／平行する低中層住棟／三層の階段状住宅／低層ガラス温室／中庭を挟む二棟住宅 |
| D 研究5 | 横長バイオ研究棟と支持付き連絡橋／観測タワー＋ラボ／三段に積層した観測施設／アトリウムを持つクリーンルーム／高低差のある二棟ラボと地上接続 |

各敷地は48×48以下の主建築領域に制約し、旧道路12幅と中央の市民空間用地は残す。一次形状の上部部材は下部部材上面との少なくとも6セルの接触面を持つ（**建築的な構造強度そのものを保証する試験ではない**）。Y2以上・Y78以下で計画し、道路Y0–1の共有Clone案とは独立して評価する。

## 4地区の中央公共空間を実際に構成

単に「空き区画」があるだけでは、今回の3D画像のように都市が疎らに見える。A2では中央区画も各地区で別の都市体験として整備する。主建築22棟とは**別の中央公共施設4件**であり、全都市の公共床・周辺建築との利用経路は今後確認する。

| 公共核 | 配置した要素 |
|---|---|
| A | 業務・交通を結ぶ公共広場＋左右の低い交通施設 |
| B | 中央屋外舞台＋左右の客席＋バックヤード |
| C | 大きな公園＋西の温室＋東の植栽テラスと小さなパビリオン |
| D | 科学展示広場＋実験・展示翼＋地上に接合したギャラリー |

公共広場の中央には頭上の空間を残す。すべて`A0/B0/C0/D0`の独立パーツとして建築データに含め、道路12幅と主建築の22棟カウントを維持。**ただし床は今のモデルではsolid boxで、内部AIRや実際の歩行品質は保証しない。**

## 新しい合格基準

- 4地区それぞれ**最低3種の異なる構造型**、同型3棟以上の反復なし。寸法・高さ・材質だけを変えたものは独立形式と数えない。
- 8方向の全景/地区近接の3Dプレビュー（都市：正面/側面/斜視/俯瞰、地区ごと斜視）の計8方向図、OBJ・MTLをCIで保存。
- 多視点目視審査では「公共文化施設が箱の積み重ねに見えないか」「研究棟の橋が建物本体と一体か」「住宅の中庭が実際に開いて見えるか」「巨大屋根が支持されているか」「地上から巨大公共建築として読み取れるか」を判断。
- 自動検査の`REQUIRES_HUMAN_ART_REVIEW`は **合格ではなく最終評価の保留**。旧G4C6の実機美術REJECTは独立に保持。
- 他プロジェクトの高度なART-FIRST作品と混同しない。これはMakeCode Educationの高速都市構築のための現実的な縮尺の試作。
