## 2. 視覚設計の具体的契約

**人間目線S1契約：**

1. 目線を**実際にモデル化した足元床面から高さ1.7m**に固定し、シーン完成前の仮想スプライン高度を歩行者の高さと混同しない。
2. 一つの公共ホールから市場の奥行きと台・人、文化工房の制作面、研究閲覧の棚・席を、それぞれ独立の建築空間として見せる。文字・材質だけのラベルで認識させない。
3. 人物、入口、家具の大きさが建築外郭と矛盾しない。人物は遠景の装飾ではなく、居住可能な室のスケール判断に使う。
4. 上からの光と側面の採光を分け、3用途が巨大屋根で暗く覆われたら直ちに停止。誤魔化す追加照明は不可。

**同一建築の遠景契約：**

1. 市場・文化、研究・学習、居住地区が「空中に浮く床板」ではなく壁・室・テラス・窓を持つ**占有された厚み**として実在すること。
2. 二つの壁が谷を挟む輪郭を禁止という形式的規約ではなく、主要視点の**最初の印象**が峡谷・採石場・単独屋根・大学キャンパスに見えるなら即REJECT。
3. 大・中・小の輪郭が同じ模型的要素の反復にならず、街区の用途、交通結節、人間の居場所に応じて異なる。無意味な窓グリッドや豪華な材料で説得力を装わない。
4. 立体接続は外から見える**実際の使われる室・廊下の厚み**を伴い、棒状Bezier経路を歩ける橋と呼ばない。
