## 3. A78の次の真正3Dを設計するための具体的な方式：共有空間境界ケージ

これは**未制作・未審査の作業仮説**。候補名より制約とメッシュ生成手順を優先する。

1. **外殻先行でも部屋先行でもない単一編集原本**：都市遠景を決める非反復の外境界制御点、都市の実際の活動空間の内境界、街路の接続線分、主要支持ルートを、同じ三次元制御ケージ内の共有頂点／共有辺として記述する。大きな床を一定高さ間隔で作る命令も、用途につき1棟作る命令も外形決定には使用しない。
2. **同じ境界の表裏が外観と用途になる**：公共街路に開く市場／制作／研究閲覧／生活の少数の空間の「入口の内外・床接触・側面・視線先」を手編集し、その境界が地区の巨大形態にも直接反映されるようにする。「外側を造ってあとで中を彫る」「内側を配置してから外側を被せる」のどちらも禁止。
3. **負空間は通過／活動に結びつける**：巨大な空洞は飾りではなく、視点の異なる実公共空間へ開く複数の経路・端部・活動密度を伴わせる。リング／橋／水景を主役にする、単一の巨大チューブや巨大壁を生むだけの自動押出し／Loftに戻らない。
4. **細部前に三尺度を同時表示**：同一実3Dの (a)都市規模斜視 (b)地区の内部外部境界 (c)床位置を確認した人間目線。実景の作者判断を通らない限り多数の住宅、ディテール、テストケースを増やさない。都市全体を別モデル、局所を別モデルとして描いて整合したことにしない。
5. **A73を局所共有原本としてのみ移植**：`tools/g4c7_a73_topology_fabric.py` の、道路床と入口・実室床を同じ線分／ポリゴンから導出する原理を活用。ただしA73自体の4独立室の配置を都市全体の構成へ複製しない。局所入口の正しさと全域の歩行／支持の正しさを混同しない。

### 制作着手条件（未達）

同じ三次元制御点群で、少なくとも1つの市場・制作・研究の公共接続と、周囲の非反復な外形の共有面を説明できること。各出入口がどの実床と同一高さに接するか、都市サイズへの展開にあたり全体の形状が「棚／箱列／巨大壁／チューブ／低層キャンパス」へ戻らない理由を**実際の頂点移動や曲面拘束で**説明できること。
