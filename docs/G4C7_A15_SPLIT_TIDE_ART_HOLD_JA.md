# G4-C7 A15 — SPLIT-TIDE / 天裂双流殻（二方向比較）

**段階：研究用実体3Dの候補制作。美術ART HOLD／Minecraft Education施工禁止／都市統合禁止。**

## なぜA15か

A14はリアル3Dとして成立したが、「独立した太い蛇状の部材を追加した建築」として正面・斜視に見え、美術REJECT。しかも当初のActionsは3D生成・331/993経路QA・4視点成功の後、LIVE HANDOFF同時更新によるpush競合で永続保存が失敗した。A14専用保存ジョブはリモート更新追随（fetch→rebase→push）へ修正。

A15は「ひとつ屋根を載せる／帯を置く」を**設計手法として廃止**し、既存の大規模空洞を持つ左右のA11/A12断崖の頂部・胴体を**形状そのものとして連続変形**する。左右23個の大断崖・中空シェル・公共床・露出床・支持脚を同一空間変形させ、分離した後付け物の錯覚を減らす。旧地表・経路と結びつく低層Y<=14は恒等変換。

## 二つの異なるシルエット

- **A15-A「内流する双殻」**：高さ約141概念単位（ローカル試算）、左右の厚い内部都市断崖が互いに巻き込むように成長し、中央に巨大な負空間を残す。
- **A15-B「開花する空の断裂」**：高さ約158概念単位（ローカル試算）、中層までは中央へ引き寄せ、上部は外へ強く湾曲して空を大きく開く。Aより非日常的で大胆だが構造安定性は一切不明。

両案とも「都市全体を支える外殻を現実に曲げてよい」という建築工学の許可ではない。元の実空洞を持つ閉鎖メッシュを、研究コピー内で非剛体変形させた造形仮説。
