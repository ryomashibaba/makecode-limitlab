## 2. 二つの方向を比較して、現段階での投資対象を絞る

### A《斜交共層 / TRANSVERSE COMMONS》— **G0 早期REJECT**
複数の高低差のある居住街路を斜めに交差させ、交点に市場・工房・学習・庭を作る。人間目線では交点を賑わせやすい。しかし遠景を成り立たせようとすると長尺の居住帯が太いリボン／巨大スラブになり、接続が橋・モール化する。A53/54/A61の主生成文法を別名で繰り返す危険が極めて高い。**今回は模型化しない。**

### B《群孔生活都 / INHABITED POROSITY》— **G0 探索継続、ART HOLD**
一個の巨大岩塊に穴を開ける「採石場・峡谷」ではない。**密度の異なる複数の「住み込まれた近隣組織」が、屋外の採光ポケットと共同生活の交点を縫う**構成。遠景の主役は単独巨殻でも住戸列でもなく、異なる高度と厚みで組み合った近隣の断続的な輪郭。中景では市場・工房・居住・研究が孔の周囲の多方向の壁面と床に現れる。近景では孔の内側の公共街路自体が営業・制作・閲覧の場になる。

**決定的な違い：孔は装飾的な穴ではなく、隣接する実室の開口・公共階段・上層住居の眺望・日照の共有によって必要となる空間。** 特定の巨大プリミティブ/差分ブーリアンから「穴らしい形」を量産しない。個々の街区は、入口の方向、共用室の高さ、屋外界面、住戸への移動経路を作者が個別に描いた後で外形を閉じる。

## 3. G0図面での独立反証（結論）
[概念ボード](../artifacts/g4c7-a64-authorial-form-gate/a64_porosity_authorial_board.svg)ではBの遠景輪郭と、同一地点を**意図した**市民生活断面を同じページに並べる。ただし**同一3Dの透視投影ではない**。この作図で「生活の孔を持つ密度の異なる近隣」という語彙は具体化できたが、遠景の超未来的な圧倒感・都市階層・支える構造、近景の魅力は、独立の実画像としてまだ実証できない。特に**多孔の崖、蜂の巣、巨大集合住宅、商業施設**に見える危険が残る。

したがってBも**美術採用はしない**。A64で実3Dを実施しないのは制作環境不足ではなく、弱い形態を無理に増殖させないためのゲート判断である。次に進める条件は、Bを作者判断で描き直した**説得力ある独立の近景・遠景絵**で、双方の視覚的魅力と同一空間対応が見えること。そこで初めてBlender真正2視点の最小試作を認める。
