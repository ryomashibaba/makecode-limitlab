## 3. 参考とした実建築の設計原理（単純な形状模倣をしない）

- <https://oodihelsinki.fi/en/what-is-oodi/architecture/> と <https://ala.fi/work/helsinki-central-library/>：**Oodi**では活動的な下階、創作室を持つ中階、閲覧の上階という用途と内部・外部が構成を決める。上階の大きな形だけを模倣しない。
- <https://www.spl.org/hours-and-locations/central-library/central-library-highlights/central-library-architecture>：**Seattle Central Library**の用途に応じてプログラムを重ね、公共のLiving RoomやBooks Spiralを明示する方法を参照。「プログラムを名付けるだけ」で視覚がついてこない問題の対照にする。

## 4. 次工程A50への実3D作成条件（S1の必要条件であり十分条件ではない）

1. **真の奥行き**：市場・制作/文化・読書/研究・居住のうち最低3用途が、単なる家具タグでなく入口、利用室、外部との開口、滞在場所から成る3D空間として互いに関係づけられる設計であること。
2. **主カメラを先に決める**：到着地点1.6m程度の低い目線と内部にいる人の目線を、最初の構造生成前に固定する。左右・上層の目的地が実際に視認できない場合、モデルを厚くするのでなく空間配置を再設計する。
3. **可視性を数えるが美術合否を自動化しない**：このA49ツールで各用途の最近接面が画面に存在するかを検査する。百分率の閾値だけで合格させず、用途の実際の見た目、圧迫感、室の奥行き、スケール、光を実画像で審査。
4. **外観契約を同時検証**：近景だけの校舎や文化ホール、遠景だけの巨殻や結晶を回避するため、最低でも正面・斜視・側面・俯瞰を同一実3Dから描画し、巨大未来都市の主役造形・内部の関係を独立評価。
5. **未成立ならモデルを増やさない**：この二段ゲートをクリアできない案は、生成器の実行や新しいGLB/OBJ作成を停止する。A49の2D構想を「採択された設計」や「G1の成功」と呼ばない。
