# G4-C7 A34 — 一体切削型公共都市研究／実3D・美術監査

**実施日：2026年10月25日 JST。最終判定：A34 G1 ART REJECT、全体ART HOLD。**
**施工禁止／都市統合禁止／過去成果物完全保護。**

## 1. A33までの失敗から変えたこと

A22〜A33では、小箱街区を追加すると小型模型、主役を巨大化するとU字外殻や平行帯となり、居住都市の公共空間が独立した付属物に見える失敗が連続した。

A34では**新しい単独の3D設計研究**として、ボクセル占有グリッドから「ひとつにつながった巨大な建築本体」を作り、建築本体から以下の空気空間を**実際に差し引く**手法を実装した。南入口、中央大広場、西側の低層・上層都市室、東側の低層・上層文化室、北奥の公共ホールの計7サンプル地点。部屋の機能名は意図を示すが、現実の人が利用できる部屋であることは**まだ証明していない**。

A21の単一体積とA30の実開口メッシュの技術面を応用したが、A33のU字施設のモデルを流用して厚くしたわけではない。**建築美術の採用モデルではない。**

**検証手段：** 各ボクセルの6近傍を使って本体が1つに連結していることを確認。各占有セルと空気セルの境界面を取り出し、共有頂点付き三角形として組み立て、有向辺と逆向き辺が各1回だけ対合することを確認。2個の対角接触を修復。室の指定座標が空気セルであり、**外周から空気セルのみをたどる洪水探索で到達できる**ことを確認。

**大事な限定：** 7/7は「外の空気がつながっている」という**離散格子の検査**であり、人物が通れる幅・床・入口・階段・避難路の存在証明ではない。表面有向辺の照合と1連結体の確認だけで3D頂点まわりの完全な多様体性、幾何自己交差、力学的支持をすべて証明したわけでもない。

**GLB独立再取得：** GitHub Blob `ed0c8f4229448791409a0f61258852680263b3bd`。base64から実バイナリへ復号してヘッダー長249,448、POSITION 6,860、索引三角形13,720、6材質、bufferView範囲を照合。**さらに全6,860頂点の実バイナリ座標を独立再計算し、POSITION accessorのmin/maxが正確に一致したことを確認（PASS）。** ただしBlender等第三者ビューアでのモデル表示やBoolean操作はまだ未実施。

## 5. 内部診断：正式G2ではない

- 南入口参考カメラ `[0,35,-120]` から `[0,95,130]` を向く：空洞が内部に続くことは見える。しかし切削した室や広場は**巨大な無表情な色面・角柱の連続**として現れ、街区の個性や奥へ向かう魅力が弱い。
- 西の内部室参考カメラ `[-102,45,-75]` → `[-23,78,-7]`：実際に壁・床・天井に囲まれた大空洞を見せられるが、簡素な大部屋と側面の大穴に近い。居住活動・階層・行き先の視認性不足。
- 北ホールの参考透視も保存し、カメラ座標は`a34_interior_diagnostics.json`に記録したが、独立したラスタ目視は未完了。
- 三視点とも**歩行できる地点かを未検査**。簡易透視はカメラ近面の三角形を省いており、物理空間・避難QAの代用にはならない。

G1不合格につき、**正式G2 PASSなし／G3 NOT RUN**。A34の331人体・993足元安全QA、負の対照は未実施。

## 6. 次工程A35への改善条件

今回最重要なのは、「一体の建築マスから部屋を切り出す方法」を技術的に確認したこと。A35はこれを活かしながら**建築美術の改善**へ注力する。

1. **体積の位相・空洞連結ロジックは保護**。繰り返し実装し直さず、試験済み生成器を研究用共通基盤にする。
2. **ボクセル解像度を上げるだけでは解決しない。** 今回の階段状シルエットを滑らかにするだけでも巨大建築の公共生活は表現できない。巨大公共室の用途、居住街区の奥行き、都市の外観としての美術的秩序が必要。
3. **外形と内側を同時評価**。正面で階段の塊、斜視で巨大駐車場、内部で空っぽの部屋になっていないかを先に検査。大規模な本体の凹み、実開口、複数の異なる利用空間を一体化して構成する。
4. 一つの有望な候補を早期美術審査する。失敗形状を改修し続けない。G1不合格ならPR、CI、負担の大きい331/993正式QAへ進まない。
5. **人が使えるという主張を厳格に禁止**。空気連結QAと、足場/入口/階間移動/避難/構造荷重の検証は別ゲートのまま保持する。
6. 形状・素材・構造の**一律禁止リストを作らない**。アーチ、リング、塔、橋、曲面は役割があれば採用可。ART-FIRSTをMinecraft施工制約で最初から縛らない。

**絶対制約：ART HOLD、Minecraft Education施工禁止、都市統合禁止、全歴史的証拠保護、331人体／993足元、半幅0.65、足元高さ相対+0.15〜+3.25、歴代身体表面干渉上限45、未支持足元0、負の対照必須。** ユーザー事前承認なしのWork使用禁止。
