## 4. どの新しいコード文法がまだ失敗の原因だったか

今回`LOBES`の3つの`center / radii / lean / warp`と`np.minimum.reduce(solids)`で**居住・街路の具体的内容より先に、都市の外面をほぼ決めてしまった**。`SPACES`のボイドと戸口はその外面から後から差し引かれる二次加工にすぎない。つまり「同じSDFソースを使う」ことだけでは「都市活動と外形が相互に形を決める」ことにならない。

A78の監査で廃止したはずの外殻先行を、幾何表現を楕円体とSDFに変えることで再び導入してしまった。これが根本原因。床接合の2D面積値は本物の建築街路が成立した証拠ではなく、検査用ラベルや数学的PASSで失敗を隠さない。
