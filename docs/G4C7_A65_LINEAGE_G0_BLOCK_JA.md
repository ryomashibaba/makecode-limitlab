## 4. この段階に必要な本当の新しい設計方法
過去には【マクロ外形先行 → 彫刻】、【部屋先行 → キャンパス】、【「同時設計」と記述して基本プリミティブの反復 → 住宅台座】を繰り返した。ゆえに次の制作は『箱以外を使う』だけでは意味がない。

次に試す新案は、数km規模の印象を生む**特徴的な生活地区の組織**を絵にし、その中で固有の公共室・街路・居住階を**透視的・空間的に同定**する必要がある。見た目が旧アーチ/巨孔/谷/大学/住宅台座/モールに同一視されるならG0段階で不採用。魅力的な新方向を作れていない現段階で第2案を即興で発表しない。

### 次の実制作を解禁する「一体性」の証明
1. **遠景の意匠主張**：街区密度の非一様性と立体構造の固有性があり、最初の印象が旧類型と異なる具体的な形として見える（スローガン不可）。
2. **生活する断面**：その形を成立させる市場/工房/研究/住居/公共交流の実面を計画する。部屋の名札や色だけでは不可。
3. **同じ都市の同じ場所**：人間目線のカメラと公共空間の位置を都市マスの中で明示。2枚の異なる画像生成イラストを「同一モデル」とはしない。
4. **早期の否定権**：①②③のいずれかが弱いなら、Blender、装飾、詳細QA、施工を停止。

これらが満たされた候補が初めて現れた際に既存Blender 4.5.15/Cyclesで**公共室実床+1.7mと遠景の同一3D2視点**だけ制作する。遠景と近景が両方とも絶対水準を満たさないなら中止。G2/G3はその後。
