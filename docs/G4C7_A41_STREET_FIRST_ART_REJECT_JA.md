## 研究目的とG0

A34〜A37の採石場、A38の巨大額縁、A39の薄い高層箱群、A40の空いた大学キャンパス状断面を直接改善する。最優先は**高さ数値や複雑さではなく、人間目線から活動と行先が明瞭に読める街路**。大都市を建設する前の小さな造形試験であり、規模感そのものの合格は目指していない。

G0では二案を比較：
1. 巨大アトリウムに店舗を並べる案：A33/37の閉じた巨大容器に戻るため今回の実3D試験から除外。アトリウム・アーチ自体は永久禁止しない。
2. **ACTIVE FRONTAGE／用途が外観に現れる通り**：左右に実開口、店舗の奥行き、庇、居住のバルコニー、歩行路、街路設備と奥の読書・公共施設を組み込み、1案のみ実3D化。

## 実在建築3件から抽出した美術の設計原理

一次資料を確認した（模型の形・メートル換算をこれらと同じだと主張しない）。

- **8 House / BIG**：住宅・商業・公共歩行路が活動場所と連続し、建築そのものの利用が外から読める必要。一次：https://cdn.big.dk/projects/8-house-2021 ／補助：https://www.visitcopenhagen.com/copenhagen/planning/the-architectural-masterpiece-8house-gdk539319
- **Linked Hybrid / Steven Holl Architects**：地上の公共通路に店・教育・文化の用途が直接関係し、単なる空間トンネルで終わらない必要。一次：https://www.stevenholl.com/project/beijing-linked-hybrid/
- **Markthal / MVRDV**：商業と居住の複合用途が、屋内公共広場に視覚的にも機能的にも現れる必要。一次：https://www.mvrdv.com/projects/115/markthal.

これは参照原理の抽出であり、実建築の正確な寸法をコピーしたものではない。

## A41実画像の美術判定

| FRONT | REJECT | 建物の印象は長大な箱状の入り口であり、巨大都市は認識されない |
| OBLIQUE | REJECT | 左右の水平な屋根と箱の連続が主役で、建築としての大胆な結合に乏しい |
| SIDE | REJECT | 長い外壁・薄い建築奥行き、外部を隠す壁が明確 |
| AERIAL | REJECT | 二棟間の一本通り＝平行する商業施設、公共街区の分岐がない |
