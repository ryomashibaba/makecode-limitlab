# MakeCode LimitLab G4-C7 A9 — 偏心アーチ入口・公共床の再造形

基点：A8 Draft PR #44 / HEAD 17e3909ae7846280ef71dfe5762e48b31af5326d。研究専用A9ブランチ。

**ART HOLD／Minecraft Education施工禁止／都市統合禁止**

## 実装と建築意図

A8の実GLB（592メッシュ）を入力とし、A8の331地点うち立体干渉67地点、足元993回のうち1点不支持を修正するため、3D形状そのものを変更する。

- 南主アーチの外殻と透明ガラス帯のX54〜73、Y6.0〜13.1、Z23〜30を実ボリューム・ブーリアンで切除。内殻や北主アーチ・大部分の厚い外殻は保全し、元データは改変しない。
- 地上東西公共床から旧ランプへのアプローチは、従来の直線状床から東へ緩く湾曲する床へ**実メッシュで置換**。旧ランプの側面を潜り抜ける設計を避ける。
- A8で検出したランプ終端の横方向支持不足に対応し、接続床を旧ランプ側へ約1.35単位延長する。
- 南アーチへの入口と旧ランプ移乗口に重なる4本だけの手すり（Promenade rail.118、.119、.240、.241）を撤去し、入口外側に斜めの彫塑的なピア2本を配置。手すり端部の転落防止は未検証である。
- A8と**完全に同じ**幅1.3／高さ3.1の身体包絡、331サンプル、足元993点、13軸の三角形／AABB衝突試験を再実行。負の対照を保持し、元の67地点から改善したかを検証する。
- 正面・斜視・側面・俯瞰の固定カメラでA8/A9をGLBから比較画像化。レンダラーはBlender EEVEEではなく簡易Pillow正投影。
