## 1. 問題を5方面から審査した結果

- **建築空間：** A81には本物の4室と入口があるが、各室は道路区間ごとに一つ置かれる。A82では**一つの建築内で四用途・二層が物理面を共用できるか**を最優先にする。
- **動線：** 上下の床だけ作り接続をでっち上げない。地上z=0から高所z=24mへ、勾配約5.85366%の一本の実三角形ランプと上下の公共ギャラリーを記述。正式人体通行は未検証。

- **制作効率：** 単一研究標本、同一ソース4視点、独立した三角形検査を採用し、不採用モデルの装飾や地区コピーを実施しない。

## 4. 実画像からの絶対評価 — 4視点ともG0 ART REJECT

- **OBLIQUE：** 独立した低層4棟から一体建築への移行は見えるが、長方形の低層大箱と背面の薄い巨大フィン・斜め線で、超未来都市の巨大で本質的な空間構成がない。形態は依然として一つの簡素な施設。
- **PUBLIC EYE：** 壁板が画面の大半を占め、開口は細い切れ目。複数の活動が見える街路というより、建設中の大型施設。
- **INTERIOR EYE：** 実間仕切りはあるが、内部空間が広い無地の面に支配される。人が使う空間の使い勝手と質に不足。
- **CROSS CIVIC：** 反対側も折れ板が外装を大きく占め、後付けの造形に見える。巨大外形と内部用途の必然的な関係が読み取れない。
- **最終美術G0 REJECT、採用0**。斜めフィンを増やす、巨大化する、屋根だけ複雑にする、内装色を変える、同様の共有二層体を量産する行為を禁止。

## 5. A82の失敗が示した重要な造形文法

**A81** `道路区間 -> 個別の実室`を廃したが、**A82** `長方形の共有建築体 -> 2層を共有 -> 外に大きなフィン` も巨大未来都市として弱い。内部・外部のテクニカルな接続が成立しても、編集可能な建築が形として特別になるとは限らない。

都市の空・断崖・多層街路・大規模な生活密度が「追加の外装」でなく、都市活動の発生源でなければならない。次回は数kmの全域と代表都市断面を同時に持つ**作者設計の非矩形で不連続な複数断面**を先に比較し、毎案に具体的な通路・部屋・地形・内部実景を示す。**単一の施設型立方体を都市のコアとして昇格させない。** 不採用原型の量産より先に、世界観・機能・空間の相互依存を設計する。
