# LimitLab A2-A4 A1C — 階段ブロック4方向・小規模実機校正

**工程の目的**：G4-C5の264段はボクセル簡易モデルでは全段PASSしたが、通常の白コンクリート積層なので Minecraft 実機では1段ごとのジャンプが必要になり得る。自然に歩ける階段に改修する前に、Minecraft EducationのMakeCodeから**向き付き階段ブロック**を正しく施工できるか、独立した**小さな捨てワールド**で確かめる。

## 仕様・元資料

- Minecraft MakeCode公式の`blocks.blockWithData(block,data)`と`blocks.place(block,position)`を使う。参照： https://minecraft.makecode.com/reference/blocks/block-with-data と https://minecraft.makecode.com/reference/blocks/place
- Minecraft Bedrock系の石レンガ階段 `stone_brick_stairs` の従来数値ID **109**、メタデータは**0 東、1 西、2 南、3 北**の前提（https://minecraft.wiki/w/Stone_Brick_Stairs）。これを`blocks.blockWithData(109,d)`で組み立てる。**現行Minecraft Educationへの適用可否、向き・形状・衝突判定は未検証**。代替の`blocks.blockByName`等を今回勝手に混ぜない。
- 独立した新規ソース：`makecode/limitlab_stair_bench_a1c.ts`。G4C5のソースや49 Clone、証拠CSV/ZIP、使用済みラッチは一切変更しない。

## 設置範囲と安全性

**新しく作ったCreative／スーパーフラットの破棄可能な試験ワールド限定**。G4C4/G4C5の既存建築世界には絶対に貼らない。足元付近を変更しないよう、プレイヤーから離れた4組の位置に各6段、計**24階段ブロック**を設置。段の下部には石の縦支持を合計20 Fillで追加する。

1. あらかじめ各施工座標の地面がAIRでないことと、全ての施工列Y～Y+i+3がAIRであることを検査。どれか塞がっていれば**施工0件でSTOP**。検査を間引かない。
2. チャットコマンド`labstbonce`はセッション中1回限定、`labstbcheck`で状態のみ表示。施工途中の失敗は自動再試行しない。
3. 本ベンチはファイルを一切読み書きしない。**セッション間の永続USEDラッチは無い**ため、新しいワールドへ入るたびにプレイヤー自身が1回だけ実行し、決して同じ既存試験エリアへ2度施工しない。既存検証ワールドへの追施工は禁止。
4. CIの5テストはMakeCode APIの呼出・ID・方向・施工本数・占有検査・再実行拒否だけの**モック**。Minecraftに接続しないためハードウェアPASSにはならない。

## Windows 実機の確認項目

以下は**新規の小さな試験世界に1回施工した後**だけ確認する。

| 方向 | メタデータ候補 | 施工位置 |
|---|---:|---|
| 東向き | 0 | プレイヤーから東20/南20の地点からX+方向に6段 |
| 西向き | 1 | 東44/南20の地点からX−方向に6段 |
| 南向き | 2 | 東20/南44の地点からZ+方向に6段 |
| 北向き | 3 | 東44/南44の地点からZ−方向に6段 |

A. **階段ID成功**：設置物が想定の石レンガ階段か。置き換えた別ブロックならREJECT。
B. **向き**：低い方から高い方へ上れる形になっているか（4方向全て）。一方向でも逆転していればREJECT。
C. **通常歩行**：Auto Jump OFFで前進キーだけで6段すべてを昇降できるか。ジャンプが必要なら`WALK_FAIL_JUMP_REQUIRED`。
D. **曲がり角**：今回は**直線4種類だけの検査**。実G4C5の39段階段にある折返し角の実証はまだ無く、そのまま都市に投入してはいけない。
E. **景観**：単純な階段ブロックが建築内に自然に見えるか。実G4C5の側翼は今回変更しない。

**記録**：4方向ごとに`PLACED_CORRECT / REVERSED / WRONG_BLOCK / BLOCKED / NOT_TESTED`および`WALK_NO_JUMP / JUMP_REQUIRED / NOT_TESTED`、スクリーンショットは個人位置・ユーザーネームを隠してチャットへ。**PRには世界の座標や個人情報・画像は載せない**。

## 次工程

この小規模実機校正が全方向でPASSした場合のみ、独立した新G4C6案で既存の白コンクリート264踏み面を適切な階段ブロックへ変換する。実際の折返し角・踊り場・上階入口も個別に通行テストし、新ラン固有のSHA固定・CSV/ZIP/USEDラッチとCIを揃えて**新規捨てワールドに1回施工**する。G4C5既存ワールドへの変更は禁止。D研究地区の浮遊門、A金融地区の巨大冠など景観欠陥は別工程で修正。
