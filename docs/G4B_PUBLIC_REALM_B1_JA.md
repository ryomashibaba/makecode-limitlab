# MakeCode LimitLab — G4-B B1「街区と公共空間」実装・実機QA

## 目的と根拠
P2.4S R2は157 Fill・5 Cloneの実機サンプル完走、G4-A A1は174 Fill・5 Cloneと108回チェックの実機完走を確認済み。ユーザー画像では建物の外装が改善したが、黒い道路と灰色の空白街区、中央広場の弱さによって「8棟の模型展示場」に見える。**G4-Bでは都市空間側だけを変え、確認済み3建築ファミリーと5 Cloneを維持する。**

## 施工する公共空間（全てMinecraftブロック）

- **9街区×4辺の立ち上がった3ブロック幅歩道**：公共地面 Y+2、WHITE_CONCRETE。塔本体の36×36建築範囲とは干渉しない。
- **道路4本×縁石4辺、交差道路間の24か所のゼブラ横断歩道**：幅12のアスファルトに対し、3本ずつ明るい縞。道路の黒い床 Y+0 は維持、歩行者路面 Y+1 で明確化。
- **16本の街路樹**：8棟×2本。BROWN_CONCRETEの幹とGREEN_CONCRETEの葉冠。街区の前面セットバックだけに配置し、建物外壁には入らない。
- **8棟の実際に空いたエントランスと連続する白い歩行アプローチ、庇**：Clone後に4×4ブロックのAIR開口を追加。ファミリーごとに異なる外壁位置を指定。
- **中央公共広場**：四方からの白いアクセス路、4つの緑地、4つのシアン造形と低い座り壁。元の高さ22の中央モニュメントを保持。

既存の建築構成（192×192、8棟・3ファミリー、基準Y96以上、5 Clone）は変えない。黒・白・灰・シアン・緑を役割で使い分け、街路の生活感を追加する。

## 安全性
- 全てのブロック計画は従来の `g4bAdd` により192×192×84に制限。Fill 1回32,768 / Clone 262,144ブロック上限を維持する。
- 施工前の75点AIR調査 → 専用ラッチ確認 → 建築という順序を維持。空間検査失敗時はラッチもCSVも消費しない。
- ファイル読み込みの未定義値で「既存CSVあり」と判断しない。Windowsの新規ランダムRunディレクトリを使用し、過去のR2/G4Aファイルを一切上書きしない。
- 段階ログは従来のROADS / PROTOTYPES / CLONE / PLAZA / DETAIL / SAMPLE。**サンプル検査を従来18→22点に拡張**して、横断歩道・縁石・樹木・開口を確認。サンプルPASSは全ブロック完全一致を意味しない。
- 実機試験は破棄可能な専用ワールドのみ、従来どおり個別承認不要。ワールドの自動操作や自動再試験は実施しない。
- File Read & Write拡張が必要。エラー0件を確認すること。

## OMENでの操作（約2分の準備／施工時間は未計測）
GitHubの `dev/g4b-public-realm-a1` は G4-A ブランチを基準にした**積み重ね型のDraft PR**。既存のローカル変更がないことを確認してから取得する。

```powershell
cd "$HOME\Documents\makecode-limitlab"
git status --short
git fetch origin dev/g4b-public-realm-a1
git switch --track origin/dev/g4b-public-realm-a1
.\RUN_G4B_B1.cmd
```

`COPY OK` が出たらMinecraft Educationの破棄可能なワールドでCキー → Code Builder → JavaScript → Ctrl+A → Ctrl+V、File Read & Write拡張を保持してコードを実行。

Minecraftチャット：`labareag4b`（建築範囲確認）→ `labcityg4b`（一回施工）。必要なら `labstatusg4b` で進行を見る。

完了時の非公開ZIPは `Downloads\MakeCode_LimitLab\G4B_B1\runs\<固有ID>\private_results\USER_UPLOAD_THIS_G4B_...zip`。
チャットにZIPと**旧G4-Aに近い位置からの斜め・俯瞰スクリーンショット**を添付。GitHubに個人ワールド情報やCSVを公開しない。

完了後の作業はまず景観評価と道路→歩道の接続確認。G4-Cでは単一192×192街区を超えた巨大都市拡張を優先する。品質を落として無条件にFill数を増やす方針は採らない。

## 制約
植栽は操作と色が安定する低リスクのGREEN_CONCRETEによる**幾何学的な樹木表現**であり、自然の葉ブロックや街路灯・信号・曲線道路は次の検討対象。現状の道路は高架空中テスト構造のため、自然地形とつながらない。**G4-B実機成功・見た目改善は未検証**。GitHub ActionsはローカルMinecraftの代替ではない。
