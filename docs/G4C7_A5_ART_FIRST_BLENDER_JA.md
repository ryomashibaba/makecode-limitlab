## A4の復元と評価

既存 `tools/g4c7_render_review.js --a4` をそのまま実行し、22棟・283直方体の `source_geometry.json` を生成。各部材を `X,Y(高さ),Z → X,-Z,Y` に軸変換し、中心だけ移動してBlenderに復元した。文化地区はB0–B5だけをコピーして地区中心へ移動した。**形状・開口を美化・補修していない**。照明・概念色は共通の研究用材質で、Minecraftの見た目ではない。道路はA4 JSONの検証対象にあっても、この再現レンダーでは箱データにない道路模様を補描していない。

4方向で、基壇上に独立した箱が並び、公共核が周囲に埋もれ、屋根は薄い水平キャップに見える問題を確認した。A4の経路PASSから美術PASSを導かなかった。

文化地区5棟と公共核を、一つの地区規模の複合構造に置き換えた別案。外周188×178、最高点66概念単位。旧48×48の個別敷地制約を外した。将来の1単位=1ブロック対応を想定できる寸法系だが、メートル実施設計やMinecraft施工モデルではない。

2. 側面の弱さを修正する**偏心した直交ヴォールト**。外幅126・高さ54、内幅94・高さ40、奥行16、X=-30。第2案のX=0は正面の中央軸を隠したので、最終案で偏心させた。各アーチ脚部には地盤からZ=2までの基礎台を追加して浮きを解消した。
3. 両主アーチを結ぶ上空空間をZ44/50の2層床とZ55の厚い頂部で作り、2本の帯の間に実開口を残した。ここは依然直方体を含むため、全体の造形完成とは認めない。
4. 幅8、厚さ2.2、Z3–23の**連続楕円回廊**。地盤に達する支持と手摺を付与。2本の幅9の地上接続ランプ、東西・南北の公共軸、9段の半円段丘広場、水面・植栽島・1.75単位の人物目安を加えた。

単なる色・高さ変更や屋根フィン追加ではなく、主構造・空洞・街路と公共床の関係を変更した。一方、完全な建物トポロジーの結合・ブーリアン整理・防火避難計画ではない。

## 22棟/4地区との差

旧A4の22棟/4地区は別シーン・別ファイルで保全。A5はBの5棟＋B0を**1件の地区複合体**として再構成しており、22棟を維持したとは主張しない。A/C/Dの設計は行っていない。機械的に数えるなら17既存棟＋1複合体という統合仮説になるが、全都市へ配置・検査していないため正式な18棟都市ではない。

## Education設計へ落とす前に必要な資料・作業

1. **造形**：側面の大壁を斜めに割る/厚い貫通開口を切る、上空H字梁を曲面帯と統合する。4カメラを固定して再審査。今回のHOLDを解除するために全都市へ増殖させない。
2. **実体空間**：楕円回廊と全外殻の交差位置を列挙し、幅3以上・頭上3以上の実開口にする。地上から中空アーチ内部、2層上空室、回廊へのルートを別々に連続床として作る。傾斜した空洞に水平床・踊り場・階段を設計し、二方向退出を検討。
3. **離散化**：Z-UPからMakeCodeのY-UPへ軸変換。主要輪郭を1ブロックに量子化し、空洞・薄い箇所を侵食/膨張で確認。外殻2単位を下限候補にし、手摺0.12や人物はそのままブロック化しない。階段はEducationの向き付き階段を設計。斜め面のFill分割、曲線の段階化、内部AIR、照明を別工程にする。
4. **検査**：全ルートの支持/頭上/隣接、負の対照、構造接合、床・開口・出口を検査。A4の証明をA5の経路へ流用しない。三角形数や体積をFill回数・実行時間に換算しない。
5. **都市**：Bの外周道路・隣接地区の高さ・視線・公共軸を統合検討。22棟維持を目的に再分割せず、プログラムの再配分を文書化する。都市統合自体は今回未実施。
