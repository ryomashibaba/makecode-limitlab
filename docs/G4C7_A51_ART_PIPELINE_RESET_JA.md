# G4-C7 A51 — ART-PIPELINE RESET / 造形手法改革・証拠先行G0監査

**基準：2026-10-26 JST／出発HEAD `0e0fea653cd8dab94e9f52bbe06dac0fde340661`。A51はG0の制作方法改革と既存A50の実メッシュ診断まで。新実OBJ/GLBおよび新S1は意図的にNOT RUN。全体ART HOLD。**

## 1. 失敗の本質：技術QAの合格は視覚美術の進歩ではない

A34–A37で単一外殻や真の空洞を作ったが採石場となった。A38–A40はキャンパス、反復床板。A41–A43は平行モール→パビリオン群→箱の積層。A44–A45は構想図が説得力を持っても、実3Dでは巨大波形屋根と暗い室となった。A46は本物の開口に成功しても駐車場的立面、A47は街路の貫通に成功してもV字巨壁、A48は明るい公共室を作っても半円劇場、A50は実室・入口・奥行きまで作っても3棟キャンパスに終わった。

構造に共通する原因は「少数種類のbox/slab/beamを繰り返して見た目の大形態を決め、後から用途や備品で意味を与える」制作文法である。**部材自体を禁止するのではなく、部材列を建築の主設計とする方針を停止する。**

A51の狙いは先に解像度や頂点数を増やすことではなく、**用途の見える公共空間と、遠景で街になる大・中・小のスケールの同時成立を、生成前に契約として残すこと**。3Dを新規生成しなかった事実を成果物数で過大評価しない。

## 2. 外部実建築の根拠：形をコピーしない

### ALA / Helsinki Central Library Oodi
出典：<https://ala.fi/work/helsinki-central-library/> と <https://oodihelsinki.fi/en/what-is-oodi/architecture/>。
- 外部の市民広場が建物内へ続く、活動的な地上階。中間階には親密な創作・スタジオ空間、上階は静かな読書空間。
- 各階の**活動・開放度・採光・空間的な深さ**の違いが立体的に建築へ反映されている。
- 今回の学習：大屋根の曲線を模写するのではなく、**一つの見通せる公共動線に異なる室の奥行きを接続する順序**。

### OMA / Seattle Central Library
出典：<https://www.oma.com/projects/seattle-central-library> と <https://www.spl.org/hours-and-locations/central-library/central-library-highlights/central-library-architecture>。
- 閲覧のLiving Room、Book Spiral、用途に応じて組み立てられた複数の公共空間が、立体的な構成と外形に関係する。
- 今回の学習：**幾何で機能を名付けるのではなく、公共室・閲覧室・動線の体験が先にあり、外形がそれに従う**。

### MVRDV / Valley
出典：<https://www.mvrdv.com/projects/233/valley>。
- 住宅・オフィスの異なる用途に加え、市街から中央の谷へ上がる公開された歩行路やGrottoが建築の一部として設計されている。
- 今回の学習：**道路・用途・巨大な外郭が同じ建築構造に属する**。岩っぽい谷をコピーするとA34–37の採石場の失敗を繰り返すため、形態模倣は禁止ではなく個別の実画像で厳格審査する。

これらは技術可能性や本プロジェクトへの適合の証明ではない。都市規模へ拡張する前に、実3Dで中景・遠景と利用の同時成立を検証する。

## 3. A51 G0：今後の「造形の文法」そのものを比較

| 観点 | A：ART-DIRECTED PROGRAM-MASS / 用途で決まる主造形 | B：PARAMETRIC FACET ACCRETION / 従来の部材成長 |
|---|---|---|
| 造形の最初の入力 | 入口からの視線、深い公共室、生活階層、居住する外郭の断面、複数遠景の美術契約 | 既存のbox/slab/beam/curve生成器の数式・部材配置 |
| 形態の決定 | まず建築として使われる断面と主要な実開口を造形。必要ならBlender等で手動編集可能なメッシュから始め、検査器だけ再利用 | 幾何生成が簡単な長方形・床板・柱列を増やし、用途を後付け |
| 利点・コスト | 造形の自由度が高いが、美術判断と編集操作の手間がかかる。早期画像QAが必須 | 自動生成・検査は速いが、A34–A50で美術不合格の反復 |
| A51判定 | **A52の条件付き研究方針として採用（建築案のART PASSではない）** | **今回の主造形には不採用**。既存OBJ/GLB・レンダラ・QAコード等は引き続き再利用 |

Aは単にBlenderやUnrealを導入するという決定ではない。**美術を先に設計する制作順序**への変更が本質。新しいアカウントや手動操作を増やすことは当然の前提にしない。

## 5. A52の事前に固定する美術・技術契約

**大目標：数km級未来都市を成立させる一体の居住された建築。小さな3室キャンパスの採用は不可。**

1. **建築経験を設計起点にする**：入口から「文化／商業／閲覧・研究」のうち3用途の活動が、独立家具でなく実際の使われる室として見える空間を先に設計する。既存の3棟配置を再使用しない。
2. **公共室と居住外形を同時に造形**：実開口と外への光、目線、奥行きのある用途帯、住区の外形を同じ設計段階で制作。内部だけを完成して、後から大屋根・箱壁を被せない。
3. **遠景に恒久ゲート**：正面・斜視・側面・俯瞰ですべて巨大な複合都市空間を予見できるか。階層床の均等反復、巨大空白、巨大斜材、別棟キャンパス、採石場、劇場単体が主役なら直ちに停止。
4. **具体的な制作手順の変更**：最初の候補は手作業で調整可能な大きな外面・中景の街区・人間目線の空間をまず一致させ、実3Dの8視点で美術監査。生成容易性に最初の設計を従属させない。既存のGLB保存・深度PNG・バイナリQAは再利用。
5. **採否根拠を複数にする**：用途ラベル面の可視性（診断）＋人間が画像を見て用途を認識できるか（美術）＋遠景の未来都市級外形（美術）。美術S1合格はG1成功と混同しない。
6. **停止規約**：主画像の時点で公共室・遠景の両立が疑わしければ、生成物や工程番号を増やさず再設計を優先。

現時点で次のA52実3D、Blender/Houdini/Unreal開発、Minecraft施工は一切着手していない。制作手法を**条件付きで研究採用**しただけで、全体のART HOLDを解除しない。
