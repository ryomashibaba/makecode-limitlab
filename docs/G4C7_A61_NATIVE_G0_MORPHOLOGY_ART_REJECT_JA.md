## 4. 最重要の再発防止策
A51/A52 → A59 → A61の共通問題は、造形生成器が最初のマクロ形態を決めることである。押し出し箱、同形状の反復、曲面ロフト、長尺リボン、可変幅の太いチューブを選ぶかどうかではない。

**A62では、以下の制作順序を強制する（同じ見かけのSVG再描画で進歩宣言しない）：**
1. まず人間が使う少なくとも**1つの本物の公共室・入口・住居群・採光中庭**と、接続して生活する2〜3街区の具体的な位置・空間容積を設計。
2. 次に、その間の**占有された混用街路**と、重なり部分の室内活動を個別編集可能な状態で設計。薄い橋はその代替としない。
3. その都市の生活組織から、遠景で特異で魅力的な形を構築する**美術的作者の判断を優先**する。単一のbox/loft/ribbon/アーチ／屋根／コーニス生成器から大量展開しない。
4. ここで初めて独立のG0造形全景を審査。巨大な彫刻、筒、3塔、山、採石場、工場、キャンパス、ショッピングモールなら即停止。A61の形を家具や窓で延命しない。
5. 目標水準に達しないなら真正Cycles／S1へ進めない。達した候補のみ、同一Blenderシーンから人間目線（床＋1.7m）と都市遠景の2枚を最小制作する。

この順序は**次案の美的成功を保証しない**。活動の可視性や建築支持の実証を省略して美術採用することもできない。
