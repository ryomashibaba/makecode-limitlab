## 1. Macro-First の都市計画

1. まず**2×2の地区（36区画）**、道路幅12／建築区画48／セルピッチ60の大都市基盤を目標とする。
2. 各3×3区画には8棟＋中央広場1つを配置。4地区合計で建物32棟、中央公共広場4つを保持する。
3. 地区のコピー間隔は192ではなく**180**。道路帯を境界で共有し、幅24ブロックの重複道路を作らない。
4. 数学上の全体フットプリントは `180×2+12=372`、つまり **372×372×高さ84**。
5. 各軸の主要道路帯の始点：`0,60,120,180,240,300,360`、道路幅12。横断帯・歩道はC0のY+1で統一。
6. 中央広場の区画始点は `(72,72)`, `(252,72)`, `(72,252)`, `(252,252)`。
7. **単純な複製都市を完成形としない。** 技術QAではC0母体の複製を利用可能だが、景観完成版は地区ごとのランドマーク、高さ変動、公園/広場構成、建築ファミリー配分に変化を入れる。機能のない同形32棟だけで完成扱いしない。

## 2. 実機施工へ向けた安全な高速複製計画

- C0 192×192を1地区の原本として最初に構築した後、**180×180のコア**（X0..179, Z0..179）を目的地区 (180,0),(0,180),(180,180) に移す。
- Minecraft `clone` の262,144ブロック実機成功実績に対して十分な余裕を持たせ、**高さ6**のスラブで分割：180×180×6=**194,400** ブロック/命令、14スラブ/地区。3地区で42 Clone。
- 世界の東端／南端道路は各12幅帯を高さ84の一括Cloneで引き継ぐ（12×180×84=181,440）。端4本＋角1本で5 Clone。原本地区の建物Clone 5回と合わせ、2×2は**計52 Clone予定**。
- 施工の出力は全体で0..371のXYZ平面境界、Y0..83を越えない。元ソースと複製先は交差しない。施工順序・境界・空き領域検査を実装後の別CIで検証する。
- 再複製領域は約 3 × 180×180×84 = 8,164,800 ブロックの命令対象体積を含む。これは実ブロック数や更新された固体数ではない。**実機性能は未知**。大規模`clone`の失敗・長時間フリーズを前提に早期に停止可能な区間チェックポイントを設計する。
- 2×2では最低**300個のAIRサンプル**を**初回ラッチ消費より先**に検査する計画。検査は不完全であり、実機施工先は新規破棄可能ワールドのみ。使用済みラッチ再利用、古いCSV削除、失敗時自動再試行は禁止。
- 複製が元建築への上書きを生まないこと、同じ12幅の境界道路に正しく接続することをオフラインで検査する。

## 3. 作業段階と品質ゲート

- **C1 A0（本工程）：** `tools/g4c1_tiling.py` が地区道路・建築区画・中核コピー・端道路Cloneの座標計画を純粋に生成。12件以上のオフライン不変条件テストを用意。Minecraftのブロック書込みは**ゼロ**。
- **C1 A1：** 別の専用MakeCodeソースで、再設計した幾何計画・事前AIR検査・分割Clone・完走CSV・独立ラッチを統合。1地区先行の低リスクQAを可能にする。G4-C C0/旧実機証拠を一切変更しない。
- **C1 A2：** 巨大2×2都市の完走と道路端の連結、4つの中央広場、32棟を実機で確認。スループットと外観をユーザーの実機写真・CSVで評価。
- **C1 A3：** 非反復の街区デザインへ拡張。中低層・高層・公共施設の比率、地区ごとの外観差、使える内部空間、地形接続を計画。既存品質を落とす無理な拡大は禁止。
