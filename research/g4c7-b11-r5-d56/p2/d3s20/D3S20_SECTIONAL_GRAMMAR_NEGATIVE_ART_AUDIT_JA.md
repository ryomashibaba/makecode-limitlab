# G4-C7 / D3S20 — 都市断面作者モデル・独立反証試験

**2026年10月31日（JST）／独立研究／ART REJECT／正式採用0／施工禁止**

## 0. 判定
**ART REJECT（試作）**。K2の「独立施設＋放射状リンク」から、市民の公共軸・共通の街路断面・街路側に開口する使用室を一度に生成するコードへ移行した。しかし実画像では細長い平行街区と反復された高所部材が櫛状を作り、独創性、巨大都市の密度・主従、実際の人間生活空間として不足。**メッシュ数2763や137室相当の生成は美術改善を示さない。** このモデルを窓や装飾で延命しない。

## 1. 実制作済み（作者スクリプトと保存GLBを区別）
- Python `section_author.py` で「公共街路＝3つの長手軸×4本の横断軸」から断面を生成。概念XYZで、床、壁、外壁開口、採光部、屋根、外部共用床、製造ホール、公共庭、上層ギャラリーを**同一作者シーン**に登録。X東/Y北/Z上。最終施工座標ではない。
- **保存GLB実測**：2,763ジオメトリ、1,612,540 bytes、SHA256 `4921e9df3eca237d84b94a2082095d26235ea72af60d4ed2f9726573b6af3e3f`。GLB再読込後のジオメトリ数一致、AABB最大差 `5.3115305149731284e-06` 概念単位。
- 保存GLBから**独立VTK**で10視点（全景2、空撮、地区、市民眼高4、上層、中央公共）を再描画。6画比較板 `SECTION_SIX_REAL_VIEWS.jpg` はこれら実画像からの合成であり、生成AI画像ではない。
- 断面外形AABBは X -360..360、Y -143.938..173、Z 7..171。D3S19の目標検討範囲 X±400、Y±280、Z0..400を**満たしたと主張しない**。横幅・高さ・生活密度の不足は明白。
- `AUTHOR_AUDIT.json` の137室は**壁床を組み立てたベイの個数**。建築基準の「実用可能な137室」や入室・歩行・避難を意味しない。

## 2. 保存GLBに対する独立の負の検査
`independent_geometry_audit.py` は作者ルールとは別に保存GLBを読込んで実三角形ベースのVTK閉体包含試験を実行。

**入口低高さの縁石干渉：137ベイ中116ベイで、入口中心の高さ9.3〜11.0に置いた点のうち少なくとも1点が保存GLBの道路縁石実メッシュ内部と判定された。** これは人体通行が不可能であることを完全証明する正式試験ではないが、「入口が本当に開いている」主張の反証として成立する。旧K2の入口上部の梁バグとは別種の設計不具合。

横断公共軸4本、各38点の高さ約床+1.2のサンプルに対し、**室壁などのAABB broad-phase**でそれぞれ7/38、4/38、8/38、6/38の潜在的干渉サンプルを検出。AABBは過大検出し得るため、**実接触の確定ではない**。それでも「横断道路が機能的に接続済み」とは主張できない。室中心点のAABB可能干渉は6ベイ。いずれも正式安全QAを代替しない。

## 3. 双方向拘束の独立反実験
`section_author.py` の同規則を2ケースで再実行し、保存GLBの対応する名前付き実ジオメトリの頂点座標を照合した。

| 変更 | 変更された部材 | 公共軸3本・横断軸4本の形状変化 |
|---|---:|---:|
| 庭・居住地変更 `garden_shift=20`（実装では庭のXと一部住居のYを変更） | 117 / 2763 | **0** |
| 居住室一群の高さ `room_height_shift=16` | 84 / 2763 | **0** |

**結論：幾何部材の依存は存在するが、生活空間の変更が公共道路・断面・外形の全体へ逆向きに効く双方向拘束は未成立。** source-levelで数字が変わることを「実機能の相互拘束PASS」とは言えない。これは作者データ構造の根本問題。

## 5. 四尺度 ART Gate0（人間の美術判断用・非公式）
1. **都市全景 REJECT：** 3つの細長い平行構造が全景を支配。前回の分散施設より連続性は増したが、今度は棚/帯/櫛形に回帰し、都市の広がりと地区の独立した個性が弱い。
2. **地区 REJECT：** 主に同型のベイを幅・高さ・色だけ変えて反復。住居・製造・公共・文化の「体験差」を形態にできていない。
3. **市民眼高 HOLD/REJECT：** 本物の3D街路から撮影したが、壁と連続する直線状部材が遠景を遮蔽し、人が歩きたい活気ある空間・目的地を示せていない。入口には116件の低い高さの干渉がある。
4. **内部・上層 REJECT：** 通路/床/壁/屋根を分離したこと自体は技術改善。ただし上層の部屋は連続室というより角柱の反復。垂直アクセスはファイル内で `RESERVED_NOT_VERIFIED` と明記した予約部材で、**本物の階段・踊り場・通行可能な室・避難経路は未成立**。

**ART FIRSTの停止判断：同じ作者文法で部材と層を増殖させない。新しい番号の量産ではなく入力契約を変える。**

## 6. 改訂設計契約（次の工程で先に実装すべきもの）
- 入力の主役を**長手軸→同型のベイ反復**から変える。全域の異なる都市体験（交易、製造、教育、文化、居住、高所交通）を、交差する公共空間の**立体的な空気容積・奥行・見通し**と同時に設計する。外形も空間もこの体験に必要な断面から生まれること。
- 実開口、実室・公共地、横断動線は**道路縁石・障害物などを含む最終保存GLB**で、まず連続空間として不成立を検出。共通形状パラメータで道路端や開口も更新させ、入口だけ動いて道路縁石が残る設計を禁止。
- 公共用途/庭/住宅の立体位置を動かしたら、**街路の実通行可能空間、室隣接、外形の双方が変化**する構造にする。外形を変えたら室有効断面・採光/支持・通路も変化すること。ソース上の定数変化ではなく、GLB再読込後の差分と空気容積/経路への影響を測る。
- 芸術面は地区ごとの用途に由来する**質的に違う空間シークエンス**で設計し、単純反復を装飾や階数・色替えで隠さない。遠景・地区・眼高・内部の4尺度が同一GLBからの真正写真であること。最大2案の本質的な仮説比較と不合格時停止の原則を維持。
- アート未成立の場合、重い正式人体試験やMinecraftでの試験施工へ移行しない。初期段階から非施工の境界・ボクセル化・コスト問題は監視する。
