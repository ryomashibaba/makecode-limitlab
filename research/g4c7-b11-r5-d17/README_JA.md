# B11-R5 D17 — 公共文化体験からつくる都市の作者設計（2D先行）
2026-10-28 JST。Draft PR #53継続。D16 の巨大庇・薄板・細柱の形を修正するのではなく、**人の眼高に見える制作・研究・生活から遠景の造形が必然的に生まれるか**を比較する。

## 作品の中心となる一場面
午後の公共文化広場。制作の実演を見学する人が、向かいの公開研究室で検証する研究者も同時に見える。住居の窓・回廊から人が行き来する。公共広場に空が見え、室内外の活動は雨から守られる。地上から二つの上層交通コアへ自然に進めることが将来の必須条件。

ここでは **C1とC2は形態原理の異なる2案** であり、同じ生成式の感度比較ではない。

## C1《潮縫いの公共谷》 — 条件付き研究継続
- **眼高の主役**：制作公開工房と公開研究室が対向する、空に開いた文化広場。
- **遠景の主役**：公共文化谷が削り取った、非対称な厚い居住地形の縁。無関係な外殻は置かない。
- **支持仮説**：地上からつながる厚い居住・制作・研究建築が自ら広場を縁取る。荷重計算はない。
- **生活**：上層の居住街路が広場と視覚的に関係する。ただし実3Dの視認は未確認。
- **動線**：両側のE1/E2候補は描いたのみ。エレベーター・階段・避難経路・連続掃引は未設計。
- **D10/D11/D13からの注意**：巨大断崖や外殻が再び活動を隠す危険。厚い建築を小さくしただけなら美術進展ではない。
- **作者判定**：2D構想として研究継続の余地。ただし巨大壁へ退行する弱点が強い。**ART HOLD、採用0件**。現図の3D化は承認しない。

## C2《織り上がる文化結節》 — 早期否決
- **眼高の主役**：生活街路を大きく持ち上げてできる屋根下の文化広場。
- **遠景の主役**：一本の巨大な居住アーチ。
- **支持仮説**：両脚に生活を含む厚い都市構造を置く。ただし長大スパンの工学的根拠なし。
- **問題**：D7の巨大梁・浮遊感が大きな居住橋として再発。一本のアーチが強すぎ、都市地区の複雑な生活が見えない。天候保護はできそうでも採光は未証明。
- **作者判定**：**PRE-3D ART REJECT**。装飾・曲率変更・3D量産を停止。

## 活動が形を生むか：反証実験の設計
C1については次の3条件を**今後の作者原図**で設計し、同じ視点・同じ投影で比較する。
1. 基準：制作実演・公開研究・居住が共存。
2. 研究無し：研究公開の需要が消えることで、**研究側の居住地形と広場の外縁が意味をもって縮小・再編**される。庇の頂点差だけでは不足。
3. 制作無し：制作機材の体積・搬入経路・公開展示を必要としなくなり、**対向する建築の間口や谷の幅**が根本的に変わる。

これはまだ測定前の仮説であり、差分面積や美術改善は主張しない。

## 次の意思決定
