# MakeCode LimitLab — B11-R5 D46・D47 真正3Dおよび美術停止判断

**日付**：2026-10-29 JST。既存のDraft PR #53、ブランチ `dev/g4c7-a17-monolithic-rift-fold-art-study` のみに研究成果を保存。`main`変更なし。

## 制作と検証の実体

D44-D45の2つの実3D美術試作がいずれも美術REJECTだったため、D46はD42由来の真正中空居室、36段折り返し階段、上階床・入口・制作・研究設備を読み込み、共同で利用する公共文化室を人間目線で造形し直す試験とした。2案（A／B）の保存GLBを生成し、A基準、B基準、B制作なし、B研究なしの**4条件の真正GLB**を保存。真正GLBを再読込して各案6視点を描画した。Blender製作品ではない。使用環境はPython／Trimesh／VTK。画像は美術合格を偽装する概念レンダリングではなく保存メッシュの画像である。

## 6視点の美術評価 — A/BともART REJECT

Aは中央の大型スクリーン状の塊が残り、D29/D32型の支配的な庇・横長壁を再導入してしまった。BはAの遮蔽性を減らし、制作の活動壁、研究の観測レンズと共用上階縁を追加したが、画面に現れたのは元のD42の階段・上階居室・設備と、孤立する少数の追加三角形・帯だった。**元の空間の優先順位・輪郭・通行体験はほとんど変わっていない。** 過去の不採用形態から明確な美術的前進は見られない。

D47の独立した描画画像の比較は、A/B共通の127部材のメッシュ座標がすべて一致し、B全138部材の**92.03%が同じメッシュ**であることを示す。画素差の定量結果は、同一視点・同一解像度のA/B画像でRGB最大チャネル差20を超えたピクセル割合：

| 視点 | A→Bで変化した画素 |
|---|---:|
| 遠景 | 0.904% |
| 入口 | 4.568% |
| 人間目線の公共室内 | 5.555% |
| 制作 | 12.059% |
| 研究 | 0.763% |
| 上階居室 | **0.000%** |

**注意**：これは美しさ・新規性の自動スコアではない。撮影条件で変わる見た目の類似性を示す**探索的診断**であり、「2%」という参考ラインは公式基準でも事前登録された合否基準でもない。最終的な美術REJECTは実画像の独立した審査による。

## D46の限定的な真正メッシュ独立監査

- 保存GLBのメッシュノード数：A 129、B 138、B制作なし 114、B研究なし 120。
- Bでは制作を削除すると専用部材24件、研究を削除すると専用部材18件が消え、専用の設備・環境部材も消える。
- しかし**制作削除時の建築のX最小値は変化する一方、研究削除後のX最大値は変化しない**。研究活動によって建築全体の輪郭が必然的に決まることは未成立。
- 上階居室の実床・壁に分割された入口・窓・上階着床と、階段18×2段を保存GLBから再確認。階段・上階床の公称上面4.00／7.24、入口公称幅5.0・高さ3.76。指定3対の床上面がXYで交わり、室内4代表地点には壁等の外接範囲内に収まる埋没がない。
- 制作・研究を削除した反事実のGLBを再読込し、独立監査。採用偽装・正式QA偽装・中空床の欠落・入口塞ぎ・階段破損・上階接続断絶・消去漏れ・両活動の専用構造欠落、**9/9の故意破損を検出**。
- 以上は局所幾何であり、人体の体積掃引・室内環境・換気・手すり・防火避難・構造支持・全天候性の検査ではない。

## 再発防止方針：D48は「部材追加」から離れる

D46のA/BいずれもD42由来の大部分の視野が変わらなかった。次回は今回のソースにさらに薄い面や小道具を追加して新案と呼ばない。**先に基本的な空間組織そのものを描き直す**ことを採用候補の必要条件とする。具体的には、地上の公開制作・研究と上階生活の間を人が連続的に経験する主役となる断面を、外形・空隙・床・入口・上下接続とともに一度に造形する。D42の中空居室・階段の検査済み幾何は参照し、機能を無用に作り直さない。しかし試作形態が見た目の基準に届かなければ**美術で早期停止し、その形を拡張しない**。
